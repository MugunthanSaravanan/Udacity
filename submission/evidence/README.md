# Assessment evidence checklist

Capture screenshots only after running the real agent with the relevant live integration. Do not edit screenshots to imply that a tool ran or that a result was verified. Review images for credentials, personal data, and private session details before submission.

- [ ] Datastore search: opening hours from the indexed store document.
- [ ] Datastore search: Betty's history or other Betty-specific information from an indexed document.
- [ ] Google Search grounding: bird identification question with available attribution.
- [ ] Google Search grounding: bird diet question with available attribution.
- [ ] Product database: product price lookup showing the tool request and response.
- [ ] Session ID visible in the ADK UI.
- [ ] Relevant tool requests and tool responses expanded in the UI.

For each capture, note the date, the test question, and whether it used the datastore, live database, or Google Search grounding. This repository contains no newly fabricated screenshots or claims of live verification.
